Retail Sales Performance Analysis

Overview

An exploratory data analysis project investigating retail sales performance, profitability, customer segments and discounting patterns.
Technologies
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook

Objectives

Identify the highest-performing customer segments.
Compare sales and profitability across regions.
Investigate the relationship between discounts, revenue and profit.
Visualise business performance through charts.

Methodology

Used Python and Pandas to explore, group and aggregate sales data. Created visualisations with Matplotlib to compare performance across categories and identify trends.

Project Files

The Jupyter Notebook contains the analysis, Python code and visualisations.
