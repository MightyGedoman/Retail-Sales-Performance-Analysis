Retail Sales Performance Analysis

Project Overview

An exploratory data analysis project investigating retail sales performance, profitability, customer segments and discounting patterns using Python and SQL.

The aim is to identify business trends and explore factors associated with sales performance and profitability.

## Technologies Used

- **Python** — Data analysis and processing
- **Pandas** — Data cleaning, grouping and aggregation
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualisation
- **SQLite / SQL** — Database querying and data retrieval
- **Jupyter Notebook** — Interactive analysis and documentation

## Project Objectives

- Identify the highest-performing customer segments.
- Compare sales and profitability across regions.
- Investigate relationships between discount levels and profit.
- Explore product category performance.
- Identify patterns associated with loss-making sales.

## Methodology

1. **Data Preparation:** Loaded the retail dataset using Pandas and checked for duplicate records.
2. **Exploratory Analysis:** Examined sales, profit, discounts, customer segments and regional performance.
3. **Data Visualisation:** Created charts using Matplotlib to compare business metrics and explore relationships.
4. **SQL Analysis:** Used SQLite and SQL queries to calculate aggregate sales metrics.
5. **Interpretation:** Reviewed visualisations and summarised findings to support business understanding.

## Project Files

- `superstore/sales_analysis.ipynb` — Main Jupyter Notebook containing analysis and visualisations.
- `superstore/data.csv` — Retail dataset.
- `superstore/main.py` — Python analysis script.
- `superstore/queries.sql` — SQL queries.
- `superstore/sql.py` — Python script for querying SQLite.
- `superstore/superstore.db` — SQLite database.

## How to Run

1. Download or clone the repository.
2. Install the required Python libraries: `pandas`, `numpy`, `matplotlib` and `jupyter`.
3. Open `sales_analysis.ipynb` in Jupyter Notebook from the `superstore` directory.
4. Run the notebook cells to reproduce the analysis.
